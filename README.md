## 🔥 Featured Project

### 🧠 [Biomedical RAG Assistant](https://github.com/Sunil-tagore/biomedical-rag-assistant)
A question-answering assistant for biomedical documents, built from scratch and deployed live.

- **Stack:** LangChain, ChromaDB, Llama 3.3 (via Groq), Docker
- **Approach:** Hybrid retrieval so answers are grounded in the source documents
- **Deployment:** Containerized with Docker and hosted on Hugging Face Spaces
- 👉 [**Try the live demo**](https://huggingface.co/spaces/sunilveluturi/biomedical-rag-assistant)
